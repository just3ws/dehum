# Speech Recognition Transcripts & Forensic Diff Telemetry

This directory contains Whisper speech-to-text transcripts generated from both the raw corrupted field recording and the restored video, alongside the automated lexical diff telemetry.

---

## Files

- `transcript_orig.txt` & `transcript_orig.json`:
  Whisper transcript generated directly from the untreated raw footage (`VID_20261009_111445043.mp4`). Due to the 60 Hz hum, harmonic overtones, and corona discharge clicks, Whisper suffered from high word error rates, missing speech segments, and hallucinations on trailing silence.

- `transcript_fixed.txt` & `transcript_fixed.json`:
  Whisper transcript generated from the restored footage (`VID_20261009_111445043_fixed.mp4` / `8LYHo1dOkMo`) processed via `fix_video.sh`.

- `TRANSCRIPT_DIFF.md`:
  Telemetry report generated by `bin/compare_transcripts.py` measuring a 93.3% normalized lexical match and identifying 152 acoustic errors unmasked by the DSP restoration pipeline.

---

## Telemetry Tooling

To regenerate the comparison report:
```bash
python3 bin/compare_transcripts.py \
  data/transcripts/transcript_orig.json \
  data/transcripts/transcript_fixed.json \
  -o data/transcripts/TRANSCRIPT_DIFF.md
```
